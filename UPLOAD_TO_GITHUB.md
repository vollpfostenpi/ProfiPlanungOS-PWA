# 1:1 GitHub Upload

Lade den kompletten Inhalt dieses Ordners direkt in die oberste Ebene deines GitHub-Repositories `ProfiPlanungOS-PWA`.

Die wichtigsten Dateien müssen danach direkt sichtbar sein:
- index.html
- app.js
- styles.css
- manifest.webmanifest
- service-worker.js
- README.md
- .nojekyll
- icons/
- .github/workflows/pages.yml

Danach in GitHub: Settings -> Pages -> GitHub Actions.
Auf dem iPhone anschließend die GitHub-Pages-Adresse in Safari öffnen -> Teilen -> Zum Home-Bildschirm.
